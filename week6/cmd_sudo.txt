SPI

sudo raspi-config
창에서 : Interface Options → SPI → Enable
sudo reboot

sudo apt-get install python3-dev
git clone https://github.com/doceme/py-spidev.git

cd py-spidev
make all

• Python3 사용 시 Makefile 수정
PYTHON ?= python → PYTHON ?= python3

• 장치 파일 확인:
ls -al /dev
• 아래 파일이 있어야 정상적으로 활성화:
spidev0.0
spidev0.1 

I2C
sudo raspi-config
창에서 : Interface Options → I2C→ Enable
sudo reboot

sudo apt-get install python3-dev

sudo apt-get install python3-smbus libi2c-dev
sudo reboot

ls -al /dev
아래와 비슷한 문구가 있으면 I²C 활성화 완료:
crw-rw---- 1 root i2c 89, 1 Sep 22 15:00 i2c-1

테스트 툴 설치:
sudo apt-get install -y i2c-tools
i2cdetect -y 1
